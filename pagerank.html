Simulador básico de PageRank

Este ejemplo calcula la relevancia de tres páginas A, B y C. A enlaza a B y C; B enlaza a C; y C enlaza a A. En cada paso se actualiza el vector de rankings usando la ecuación r(k+1) = M · r(k).

Grafo de páginas

Iteración 0
Mayor ranking A / B / C
Diferencia máxima —
Página A 33.33%
Página B 33.33%
Página C 33.33%

Matriz de transición M

A B C
A 0 0 1
B 1/2 0 0
C 1/2 1 0

Fórmula aplicada

Vector inicial: r(0) = (1/3, 1/3, 1/3)

En cada iteración: r(k+1) = M · r(k)

Con esta matriz:
A recibe ranking desde C.
B recibe la mitad del ranking de A.
C recibe la mitad del ranking de A más todo el ranking de B.
